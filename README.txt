INVENTORY MANAGEMENT SYSTEM PROJECT (SQLITE VERSION)

TECH STACK:
- HTML
- CSS
- JavaScript
- PHP
- SQLite

FEATURES:
- User registration and login
- Dashboard with summary cards
- Product management
- Supplier management
- Stock in / stock out
- Low stock alert
- Reports and printable inventory summary

HOW TO RUN:
1. Extract the folder.
2. Open terminal in the project folder.
3. Run:
   php -S localhost:8000
4. Open:
   http://localhost:8000
5. On first run, open:
   http://localhost:8000/init_db.php
6. Login with:
